# 东亚银行信用卡账单导出

**简体中文** | [粤语（繁體）](README.zh-HK.md) | [English](README.en.md)

**非官方**油猴脚本：把东亚银行（BEA）网银里信用卡「交易纪录」的所有分页一次收集起来，导出一个干净的 CSV，并在页面上直接显示本月的消费、退款和净消费合计。不用再一页一页地复制。

## 安装

1. 给浏览器装上 [Tampermonkey（油猴）](https://www.tampermonkey.net/) 扩展，Chrome、Edge、Firefox、Safari 都可以。如果它提示需要打开「允许用户脚本」或「开发者模式」，照提示打开即可。
2. 点这里 **[安装脚本](https://github.com/jackdhch/BEAHK/raw/main/bea-credit-card-export.user.js)**，油猴会弹出安装页面，点「安装」。

以后发布新版本，油猴会自动更新，不用重装。

## 使用

1. 登录东亚网上银行，打开信用卡交易纪录页面，选好日期范围，点「顯示」。
   想从本月 1 号开始查，可以直接点面板上的 **From 1st**，它会把开始日期改成 1 号并重新查询。
2. 点右下角面板上的 **Auto collect**，脚本会自动翻完所有页。
   如果某一页自动翻不过去，面板会提示你手动点下一页，脚本会接着收集。
3. 点 **CSV** 下载文件。

面板上其余按钮：**Stop** 停止，**Reset** 清空重来；**Page delay** 是每页之间等几秒，网银慢时调大一点；**Latest month only**（默认勾选）表示只导出最近一个自然月。

## 导出的 CSV 长什么样

| Posting Date（记账日期） | Transaction Date（交易日期） | Description（说明） | Amount（金额） | Type（类型） |
|---|---|---|---|---|
| 2026-05-01 | 2026-04-30 | SHOP A HK | 1234.00 | expense（消费） |
| 2026-05-03 | 2026-05-02 | SHOP A HK | -20.00 | refund（退款） |
| 2026-05-04 | 2026-05-04 | PAYMENT FPS | -500.00 | payment（还款） |

- 金额统一为：**消费是正数，退款和还款是负数**。网银页面自己用哪种正负号写法都不影响，脚本会自动识别。
- 日期统一为 `年-月-日`，Excel 不会把日和月弄反。
- 用 Excel 或 WPS 求合计：消费 `=SUMIF(E:E,"expense",D:D)`，退款 `=-SUMIF(E:E,"refund",D:D)`，或者直接对「Type」列做数据透视表。

## 隐私

脚本只在 `online.hkbea.com` 页面上、在你自己的浏览器里运行，不申请任何特殊权限（`@grant none`），**不发出任何网络请求**，CSV 也是在本地生成的。整个工具就是一个可以直接阅读的文件，安装前欢迎先看一遍。

## 从 v6 升级

先在油猴里删掉旧脚本，再按上面的方法重新安装一次（v6 是复制粘贴装的，不会自动更新；从 v9 开始会自动更新）。v9 的变化：

- CSV 顶部不再放公式，只有数据，方便导入记账软件；合计直接显示在面板上。
- 新增「交易日期」和「类型」两列，日期改成 `年-月-日`。
- 商户名里带 PAYMENT 字样的消费，不会再被误当成还款漏算。
- 不再在打开页面时自动改日期、自动查询，改成手动点 **From 1st**。

## 不能用了怎么办

银行网页会改版。请到 [Issues](https://github.com/jackdhch/BEAHK/issues) 反馈，写上：用的什么浏览器、面板上显示了什么、浏览器控制台（按 F12 打开）里以 `[BEA]` 开头的几行。**不要贴真实的交易内容和卡号**，请先打码。
